# Happy English Adventure v19 - kid-chest FIXED OPEN

一個給幼齡孩子玩的離線英文單字學習遊戲。透過圖片、發音、短回合測驗與開寶箱獎勵，讓孩子願意反覆練習英文單字。

## v19 更新重點

- 首頁文案改成更童趣，強調聽聲音、答題、開寶箱。
- 「我的檔案」改成「我的寶物」。
- 「錯題本」改成「小精靈複習」。
- 測驗新增 5 題模式，並設為預設題數。
- 測驗完成後直接進入寶箱獎勵流程。
- 寶箱畫面放大，點 3 次開啟，每次點擊都有音效與動畫。
- 開出獎勵後提供「再玩一次」與「回主題」按鈕。
- 測驗中加入明顯的「回首頁」按鈕。
- 發音圖示改成更直覺的喇叭。
- 獎勵圖片集中在「我的寶物」中瀏覽。

## 功能特色

- **圖片學習**：看圖片、聽發音，認識英文單字。
- **闖關挑戰**：聽聲音選圖片 / 看圖片聽聲音選答案。
- **小精靈複習**：自動記錄需要再練的單字，方便重新挑戰。
- **寶箱獎勵**：完成測驗後可以開寶箱，收集角色獎勵圖。
- **我的寶物**：集中瀏覽已獲得的獎勵圖片。
- **離線使用**：無需網路，雙擊 `index.html` 即可執行。

## 檔案結構

```
├── index.html          # 主頁面
├── app.js              # 遊戲邏輯
├── data.js             # 單字資料 + 嵌入圖片（Base64）
├── style.css           # 樣式表
└── jszip.min.js        # ZIP 壓縮支援
```

## 使用方式

1. 雙擊 `index.html` 用瀏覽器開啟。
2. 建立玩家檔案並選擇角色。
3. 選擇「看單字」或「開始挑戰」。
4. 完成挑戰後點寶箱 3 次取得獎勵。
5. 到「我的寶物」查看已收集的獎勵圖。


## 開啟提醒

請先「解壓縮整個 ZIP 資料夾」，再雙擊資料夾內的 `index.html`。不要在 ZIP 壓縮檔預覽畫面中直接雙擊 `index.html`，否則瀏覽器可能讀不到 `app.js` 或 `data.js`，畫面會空白。
